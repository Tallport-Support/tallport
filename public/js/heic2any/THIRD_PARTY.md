# Third-party components in heic2any.min.js

heic2any 0.0.4 (MIT, see LICENSE.md) is used unmodified, as published on npm
(https://www.npmjs.com/package/heic2any, source: https://github.com/alexcorvi/heic2any).
Its single file bundles:

- libheif (https://github.com/strukturag/libheif), compiled to JavaScript/WebAssembly,
  licensed under the GNU Lesser General Public License v3.0
  (https://www.gnu.org/licenses/lgpl-3.0.html). Its source is available from the link above;
  the bundle can be replaced with one built from a modified libheif.
- gifshot (https://github.com/yahoo/gifshot), MIT License.
